# Discussly 🗨️

A Reddit-like discussion platform built with modern web technologies. This repository contains the backend API and core server implementation.

## Architecture

- **Backend**: C# ASP.NET Core Web API
- **Real-time Communication**: SignalR
- **Architecture**: MVC Pattern
- **Containerization**: Docker
- **API**: RESTful API
- **Testing**: xUnit

## Implemented
- ✅ User authentication and authorization
- ✅ Communities (Subreddit-like functionality)
- ✅ Posts with voting system
- ✅ Comments with nested replies
- ✅ Real-time notifications
- ✅ RESTful API endpoints
- ✅ Docker containerization
